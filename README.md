# msabridogruyol.com

Kişisel web sitesi (GitHub Pages).

## İçeriği güncellemek

Tüm metinler ve linkler **`data.js`** dosyasındadır. HTML'e dokunmadan:

- Yeni yayın eklemek için `publications` listesine bir öğe ekleyin (`type`: `article`, `paper` veya `thesis`).
- Linkleri `links` bölümünden değiştirin (Arkhedemia, Arkhebook, LinkedIn vb.).
- Deneyim, proje ve topluluk bilgileri ilgili listelerdedir.

Her metin `{ tr: "...", en: "..." }` biçimindedir.

## Dosyalar

- `index.html` — sayfa iskeleti ve SEO etiketleri
- `data.js` — içerik
- `assets/site.css`, `assets/site.js` — tasarım ve davranış
- `veri-koprusu.html` — Power BI paneli sayfası
- `img/` — görseller
